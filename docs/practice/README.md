# Practice

Two ways to find out whether you actually learned it.

* **[Exercises](exercises.md)** — ten functions to implement from scratch, in
  Python or C++, with an automatic scorecard. No OpenCV allowed; writing the
  maths yourself is the point.
* **[Quiz](quiz.md)** — 28 questions covering every chapter, answers folded
  away. The same bank runs interactively in the terminal:

  ```bash
  uv run python/quiz/run_quiz.py            # 10 random questions
  uv run python/quiz/run_quiz.py --topic D  # one topic
  ```

Each quiz question links back to the [chapter](../course/) that answers it, so a
wrong answer tells you what to reread.
