# The course

Six chapters, meant to be read in order. Each one ends where the next begins,
and each names the example program to run alongside it.

| # | Chapter | Run alongside |
| --- | --------- | --------------- |
| 1 | [The pinhole model](01_pinhole_and_projection.md) | `01_pinhole_projection` |
| 2 | [The K matrix](02_the_K_matrix.md) | `02_k_matrix_anatomy` |
| 3 | [The D vector](03_the_D_vector.md) | `03_distortion_anatomy` |
| 4 | [Resize, crop and ROI](04_resize_crop_and_roi.md) | `04_resize_crop_roi` |
| 5 | [Undistortion](05_undistortion.md) | `05_undistort_and_alpha` |
| 6 | [Calibration in practice](06_calibration_in_practice.md) | `06_calibrate_synthetic` |

Keep the [viewer](https://cyhunblr.github.io/learn_camera_intrinsics/) open in a
tab while you read. When a chapter names a parameter, move it.

Conventions, notation and the reading order live in the
[documentation index](../README.md). When you finish a chapter, do its
[exercises](../practice/exercises.md); when you finish all six, take the
[quiz](../practice/quiz.md).
